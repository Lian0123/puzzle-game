# 拾景 · 風景拼圖

一款純 HTML、CSS、JavaScript 的手機拼圖遊戲。收錄 800 張本專案原創風景圖，使用 OpenAI 內建圖像生成工具逐張製作。第 306～500 關先前過於簡化的程序圖片在本次逐張重製。沒有使用第三方照片、商標或角色素材；圖片並非對特定現存作品的複製。這是素材來源說明，不構成法律保證。

網頁版：https://lian0123.github.io/puzzle-game/

## 遊玩

- 從第 1 關開始，完成後解鎖下一關。首頁的冒險地圖有山海／幻想／古風／原始／外星／科技／慕夏／畢卡索八個世界、四十條圖像路線，每條 20 關；尚未解鎖的關卡不預覽圖片。目前共有 800 關。第 301～400 關為原始世界，第 401～500 關為外星世界；501～600 為科技世界，601～700 為慕夏風格世界。701～800 為畢卡索風格世界。801～1000 的達利及浮世繪世界已定義製作規則，尚未開放。完整安排見 [拼圖世界規劃](PUZZLE_ROADMAP.md)。
- 在手機上把任一方塊拖到棋盤上的任何另一塊方塊，即可交換；也可依序點選兩塊方塊。鍵盤方向鍵可與鄰格交換。
- 可選 4×4、5×5、6×6。每局有 2 次提示，會標出一塊及其正確位置。
- 完成紀錄與進行中的拼圖保存在瀏覽器本機。手機返回鍵會保護進行中的盤面；首次連線會準備遊戲介面並沿用既有離線圖片。新圖片在連線時按需快取；在世界路線頁可保存該世界完整 100 張圖片，供離線遊玩。
- 更新版本時，HTML、CSS、JavaScript 會優先向網路取得；Service Worker 會沿用既有已下載圖片，不會自動下載尚未保存的新世界。各世界可手動保存離線圖片並顯示進度；Service Worker 更新後會自動重新載入，既有過關進度不會被清除。
- 發布新的程式版本時，請同步增加 `sw.js` 裡的 `CACHE` 與 `VERSION` 編號，讓瀏覽器辨識為新版本。

## 遊戲大廳與新玩法

大廳採用金色立體按鈕、世界入口卡、動態關卡地圖與旅人 HUD。完成新旅程關卡會增加 100 旅途經驗，每 10 關提升一級；800 關完成後為 LV. 81。重玩不重複計入收藏與等級。手機底部選單可快速開啟冒險、挑戰、補給與收藏；遊戲中隱藏，避免遮住棋盤。

- **每日補給**：以裝置當地日期更新，七日獎勵為 20／25／30／35／40／50／80 星砂。第七日另送一個歸位羅盤；中斷後從第一日重新計算。七日徽章會永久保留。相同日期不能重複領取，日期往回調整不會再次發放簽到。
- **每日一景**：每日選出一幅風景與固定的 4×4 盤面，使用相同版本的玩家在同一日期取得相同題目；更新前保存的每日挑戰維持原圖與盤面；完成後「挑戰今日一景」會切到新版當日題目並保持可續存，更新後同一天不重複發放獎勵。首勝 80 星砂，不解鎖旅程關卡。跨日保存的挑戰可續玩，但不會完成新一天的每日挑戰任務。
- **限時衝刺**：目前解鎖關卡的 4×4 拼圖，180 秒倒數；每日每幅風景首勝 65 星砂。逾時可重新挑戰。
- **禪意時光**：不顯示計時，支援三種難度；每日每幅風景、每種難度首勝 15 星砂。特殊模式不影響旅行地圖的進度。
- **旅程獎勵**：每幅風景、每種難度首次完成給予 35～45 星砂；重玩可刷新個人最佳，不重複發放首勝獎勵。
- **補給站**：歸位羅盤（60 星砂，自動歸位一塊）、時光回溯（25 星砂，撤銷最近一次交換）、時間沙漏（40 星砂，限時模式增加 30 秒）。回溯本身也算一步，不能反覆撤銷。新玩家獲得 120 星砂與入門道具，不提供付費購買。
- **每日任務**：完成一局、交換 30 次、完成今日挑戰；達成後須點選領取。任務與領獎狀態於當地午夜重置。
- **收藏冊**：查看旅程模式完成的風景與十種收藏徽章。原有完成紀錄可繼續使用。
- **暫停與保護**：切到背景自動暫停；原圖查看會暫停計時，關閉後繼續。換難度與用新遊戲取代保存盤面時會先確認；遊戲中不提供重置或重新打亂按鈕。音效與動態設定會保存，也尊重系統減少動態設定。

遊戲資料全部存在目前瀏覽器，沒有帳號、雲端同步或伺服器排行榜。清除網站資料會移除進度。星砂與每日判定適用本機休閒遊玩，不是伺服器驗證的競賽經濟。

## 本機預覽與循環驗證

需要 Node.js 與 Python 3：

```sh
npm ci
npx playwright install chromium
npm start
```

開啟 `http://127.0.0.1:4173`。正式遊戲仍是無須建置的靜態網站，Node.js 依賴只用於開發測試。

```sh
npm run check
npm run test:e2e -- --workers=1
```

瀏覽器測試逐關開啟 301～800 關、解碼圖片並驗證盤面與保存索引，並涵蓋既有關卡的核心互動；另檢查八個世界的路線終點轉場。檢查涵蓋核心獎勵、舊版進度相容、桌面與手機互動、無障礙 WCAG AA 自動檢查，以及按世界保存離線圖片與斷網續玩。測試會把大廳、遊戲與過關截圖放到 `qa/`；失敗時保留 screenshot 和 trace 於 `test-results/`。GitHub Actions 的 `Game quality` 工作流程會在 push、pull request 與手動執行時重跑檢查，並保留畫面與失敗 trace。驗證範圍與結果見 [品質檢查紀錄](qa/QUALITY_REPORT.md)。

若使用現有 Chrome，可設定 `SHIJING_CHROME` 為瀏覽器執行檔路徑；否則預設使用 Playwright Chromium。手機測試為 Chromium 的 iPhone 尺寸與觸控模擬，尚未取代真機 Safari／Android 驗證。

## SEO 與分享

首頁包含繁體中文標題與描述、canonical、Open Graph、Twitter 分享卡、`VideoGame` JSON-LD、可直接索引的玩法說明與常見問題，以及 `sitemap.xml` 和 `robots.txt`。沒有虛構評分或評論。結構化資料供搜尋引擎理解內容，不保證特定搜尋結果版位；參考 [Google 結構化資料說明](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data)。

發布到不同網域時，請一併修改 `index.html` 的 canonical／分享／JSON-LD URL 與 `sitemap.xml`、`robots.txt`。GitHub Pages 專案站的 `/puzzle-game/robots.txt` 不會取代網域根目錄 `/robots.txt`；根目錄規則由 `lian0123.github.io` 主站管理。可在 Search Console 提交 `https://lian0123.github.io/puzzle-game/sitemap.xml`。本次程式變更尚未自動發布。

## 安裝到手機

網站需透過 HTTPS 開啟（GitHub Pages 預設提供 HTTPS）。Android 可在 Chrome 點頁面上的「安裝」，或從瀏覽器選單安裝。iPhone／iPad 請用 Safari 開啟，點「分享」→「加入主畫面」→「加入」。安裝後會以獨立視窗開啟；先連線準備遊戲介面，再到世界路線頁保存要離線遊玩的圖片。

## 素材與技術
