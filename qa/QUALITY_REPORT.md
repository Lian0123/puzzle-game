## 實作與素材

- 新增 101～120「浮空花園」、121～140「月光精靈森」，合計 140 關、兩個世界、七條路線。
- 40 幅內建 `image_gen` 個別生成的幻想風景，各為 1024×1024 JPEG，總計約 14.15 MiB；40 份 SHA-256 不重複。所有新增美術已逐張查看構圖、清晰度、拼圖線索與色彩變化。
- 新增旅人等級／經驗、世界入口、路線完成度、幻想先鋒徽章、下一站預覽、手機快捷選單、立體按鈕、修復進度 HUD、兩種幻想地圖與路線完成提示。
- 保留無重置／重新打亂按鈕，原有簽到、道具、三種特殊模式與盤面保護持續可用。
- 舊版每日挑戰保留原圖與盤面；完成後可切到新版當日題目並正常續存。同一天不因圖片池擴充重領首勝，跨日存檔不誤計今日每日任務。
- Service Worker v12 納入目錄、介面及 140 張圖片，沿用舊圖、分批補齊並顯示進度，完整準備後才清除舊遊戲快取。版本校驗避免舊版 100 張快取被誤報為新版準備完成。
- SEO、JSON-LD、分享描述、PWA 說明與 sitemap 日期同步更新。

原始 PNG 保留於生成工具輸出目錄。`tools/prepare_art.py` 僅等比縮放和轉換 JPEG；QA 拼接圖不修改遊戲素材。完整生成提示、標題與檔案對照見 [美術紀錄](../assets/level-art-manifest.json)。

## 循環檢查

先驗證關卡資料與存檔遷移，再檢查世界切換、100→101／120→121 轉場、舊每日挑戰及手機導覽，實際檢視瀏覽器截圖和全部美術，最後執行完整回歸與相關複測。

檢查過程修正了首次 JPEG 轉換的條紋、手機底部選單遮住捲動後按鈕、通關背景捲動區的焦點隔離，以及舊版／跨日每日挑戰重播後的有效保存。倒數測試固定模擬時鐘；瀏覽器採單一工作者，截圖以 CSS 像素輸出，降低圖片渲染資源競爭。兩組測試曾同時執行導致紀錄檔互相覆寫，改為依序執行後重新產生完整結果。

檢查範圍包括：簽到防重領、七日獎勵、兌換與背包上限、羅盤／回溯／沙漏、任務領獎、點選／拖曳／鍵盤交換、三種難度、暫停與原圖計時、限時逾時、禪意模式、精確保存、舊／損壞存檔、無重置按鈕及第 140 關收尾。

新增 40 關在桌面與手機逐關由地圖開啟，實際解碼各自圖片、驗證標題、16 塊盤面與保存索引；核心檢查涵蓋全部新關卡三種難度的存檔驗證。未解鎖關卡不可點選，世界／路線入口不展示鎖定原圖。離線檢查涵蓋所有 140 張圖片、斷網重載及第 140 張解碼；升級保留舊進度、沿用舊圖片，且不刪除其他應用快取。

## 重跑與驗證限制

```sh
npm ci
npx playwright install chromium
npm run check
npm run test:e2e -- --workers=1
```

美術檢視圖可用 `python3 tools/art_contact_sheet.py` 重新輸出，需要 Pillow。GitHub Actions 的 `Game quality` 工作流程使用同等檢查並保存 QA 與失敗 trace，尚未在遠端執行。

手機是 Chromium 的 iPhone 13 尺寸與觸控設定模擬，尚未取代真機 Safari／Android 或螢幕閱讀器人工驗證。一般互動測試封鎖 Service Worker，只有離線／升級情境啟用，因此部分一般截圖會顯示快取不可用。資料保存在目前瀏覽器，不含雲端同步；搜尋引擎實際收錄尚未驗證。

先前基準：2026-10-04 的 100 關版本完成 15 項核心與 48 項瀏覽器檢查；2026-10-05 移除重置按鈕後，15 項核心與 10 項相關複測通過。本報告記錄本輪 140 關版本的結果。
